RUTA DE DECISIÓN

Cadena de defensa

  1. 01
    Proyectar por origen

    Solo la forma de evidencia acotada para Suricata o Wazuh entra al límite del modelo.

  2. 02
    Encapsular valores no confiables

    Las cadenas controladas por el atacante son datos dentro de marcadores de límite explícitos, nunca instrucciones confiables.

  3. 03
    Validar la respuesta completa

    La respuesta JSON completa debe coincidir exactamente con el contrato antes de aceptar un veredicto.

  4. 04
    Verificar el canario

    La salida sin procesar y la decodificada se analizan antes de guardar la decisión.
